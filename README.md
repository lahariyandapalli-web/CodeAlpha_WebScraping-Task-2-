Project Title:
Exploratory Data Analysis using Tableau

Description:
This project involves performing Exploratory Data Analysis (EDA) on the dataset obtained from web scraping. The analysis was carried out using a no-code approach with Tableau to understand patterns and insights in the data.

Dataset Used:
Dataset collected from http://quotes.toscrape.com (Task 1 output)

Tools Used:

- Tableau

Data Analyzed:

- Quotes
- Authors

Analysis Performed:

- Explored dataset structure and variables
- Created visualizations to analyze number of quotes per author
- Identified trends and patterns in data distribution
- Applied sorting and filtering to find top authors
- Built an interactive dashboard for better understanding
